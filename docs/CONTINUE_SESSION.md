Продолжи работу над проектом **VoiceBridge** — голосовым ассистентом для
разработчиков (Rust + Tauri, macOS/Windows). Проект уже на продвинутой стадии.

**Сначала прочитай эти файлы (в них полный контекст):**
1. `docs/AGENTS.md` — структура, команды, конвенции, критичные грабли.
2. `docs/README.md` — обзор архитектуры и фич.
3. `docs/OPENCODE.md` — проверенный API OpenCode (типы SSE-событий!).

**Как запускать:** `npm install`, затем `npm run tauri dev` (dev) или
`npm run tauri build` (релиз). Проверка Rust: `cargo check` в `src-tauri/`,
фронтенда: `npm run build` в корне.

**Что уже реализовано и работает:**
- Трей с меню, глобальный хоткей записи (Cmd+Shift+V / Ctrl+Shift+V),
  сохранение состояния между запусками.
- Захват звука (cpal) с живой визуализацией уровня, выбором микрофона и
  чувствительностью.
- Локальный STT через whisper.cpp (whisper-rs, Metal на Apple Silicon): реестр
  моделей (Tiny/Base/Small/Medium, Qwen3-ASR — «скоро»), скачивание с прогрессом,
  выбор языка; модель Base — по умолчанию (автоскачивание).
- Запись: **тап** кнопки = переключение записи, **удержание** = запись пока
  держишь, плюс авто-остановка по тишине (настройка в «Настройки → Микрофон»).
- Интеграция с OpenCode: автообнаружение экземпляров (lsof + порты), список
  сессий, управление проектами (запуск/остановка `opencode serve` из UI),
  переключение инстансов (активный инстанс + автовыбор последней сессии),
  отправка промпта с потоковым стримом ответа через SSE, история сессии.
- Развёрнутое окно ответа: markdown, стрим в реальном времени, по окну на
  сессию, блоки «Вы» / «OpenCode», подтягивание истории сессии.

**Что НЕ сделано (кандидаты на продолжение):**
- **GUI-автоматизация** — `src-tauri/src/modules/automation.rs` возвращает
  пустой список; нужны системные API: на macOS `CGWindowListCopyWindowInfo`
  для списка окон, на Windows `EnumWindows`; вставка текста (симуляция клавиш /
  буфер обмена + Ctrl+V). Команда `list_windows` уже зарегистрирована.
- Подсветка синтаксиса в markdown (сейчас только оформление кода без хайлайта).
- Qwen3-ASR — whisper.cpp не поддерживает эту архитектуру (пока помечены «скоро»).
- Windows-обнаружение OpenCode (сейчас через `lsof`, это macOS/Linux).
- Автообновления (Tauri updater).

**Ключевые грабли (подробно в docs/AGENTS.md):**
- `src-tauri/.cargo/config.toml` форсит `SDKROOT=""` (иначе whisper.cpp не
  соберётся из-за FindBLAS). Не удаляй.
- Реальные типы SSE-событий OpenCode — `message.part.delta` / `message.part.updated`
  / `session.idle`, а НЕ `session.next.*` из OpenAPI-доки.
- Обычный TUI `opencode` не открывает TCP-порт; нужен `opencode serve`/`web`.
- Capability `windows: ["*"]` — обязательна для динамических окон
  `response-{sessionId}`.

Начни с того, что подтверди понимание текущего состояния (прочитай docs/),
проверь сборку, затем спроси/уточни, что именно делаем дальше (по умолчанию —
GUI-автоматизация).
