# VoiceBridge

Голосовой ассистент для разработчиков на Rust + Tauri. Работает в системном
трее и позволяет управлять компьютером голосом — без интернета, все модели
распознавания речи работают локально.

Два режима работы:

- **OpenCode** — наговорите текст, приложение распознает речь и отправит её как
  промпт в выбранную сессию OpenCode, а ответ выведет потоком.
- **GUI-автоматизация** — распознанный текст вставляется в выбранное окно
  (в разработке).

## Возможности (текущее состояние)

- **Главное окно — лаунчер**: панель проектов (запуск/остановка серверов
  OpenCode, «＋ Новый» с выбором папки) и панель сессий; клик по сессии
  открывает окно чата. Сессии с открытым окном помечаются бейджем «открыта».
- **Окно чата** (по одному на сессию, полностью независимы друг от друга):
  сверху название сессии и имя проекта, ниже полный диалог («Вы» / «OpenCode»
  в markdown с подсветкой синтаксиса), стрим в реальном времени, чипы
  инструментов, история сессии, обработка действий OpenCode
  (разрешения/вопросы), кнопка копирования у каждого ответа.
- **Панель ввода в чате**: текстовое поле + отправка + голосовая кнопка
  (тап = запись, удержание = говорить, авто-остановка по тишине). Режимы
  отправки: «сразу в чат» или «предпросмотр»; переключаются кликом по бейджу
  режима. При «сразу в чат» поле ввода скрыто.
- Звуковые отклики (начало/конец записи, отправка, получение ответа) и
  анимация «OpenCode думает» во время ожидания ответа.
- Системный трей, глобальная горячая клавиша `Cmd+Shift+V` / `Ctrl+Shift+V`.
- Локальное распознавание речи (STT) через `whisper.cpp` (обёртка `whisper-rs`,
  на Apple Silicon — с ускорением Metal). Модели скачиваются из интерфейса
  с прогрессом; выбор языка (русский / английский / авто).
- Интеграция с OpenCode: автообнаружение экземпляров, список сессий,
  управление проектами, отправка промпта с потоковым приёмом ответа.
- Сохранение состояния между запусками (`state.json`), файловый лог
  (`voicebridge.log`).

## Требования

- **Rust** (stable, через [rustup](https://rustup.rs)) — проверено на 1.98.
- **Node.js** 20+ и npm.
- **cmake** — нужен для сборки `whisper.cpp` из исходников.
- **macOS**: Xcode Command Line Tools (`xcode-select --install`) + clang.
  Apple Silicon рекомендуется (Metal-ускорение whisper).
- **Windows**: MSVC Build Tools (набор C++ для сборки whisper.cpp).

> Первая сборка компилирует `whisper.cpp` из исходников и занимает несколько минут.

## Первый запуск

При первом запуске приложение автоматически выбирает модель **Whisper Base** и
скачивает её (прогресс виден в бейдже модели в шапке окна). Также доступны:
Tiny (~75 МБ), Small (~466 МБ), Medium (~1.5 ГБ), Large v3 Turbo (~1.6 ГБ) и
Large v3 (~2.9 ГБ) — их можно скачать и выбрать в **Настройки → Модели**. Там же
выбирается язык распознавания (русский / английский / авто).

В **Настройки → Микрофон** выберите устройство ввода и чувствительность.

При первом доступе к микрофону macOS запросит разрешение.

## Работа с OpenCode

Важно: обычный TUI (`opencode` в терминале) запускает сервер внутри процесса и
**не открывает сетевой порт**, поэтому приложение не может к нему подключиться.

### Управление проектами из приложения (рекомендуется)

Приложение само поднимает и останавливает серверы OpenCode — терминал не нужен:

1. В режиме **OpenCode** появляется панель **Проекты** — список папок, где были
   сессии opencode (читается из БД opencode).
2. Кнопка запуска (иконка «play») запускает headless-сервер `opencode serve` для
   выбранной папки (на своём порту, стабильном для этого проекта). Кнопка
   остановки (иконка «stop») — останавливает.
3. Запущенный сервер появляется в панели **Сессии** (обновляется каждые 5 секунд)
   вместе со своими сессиями. Кликните сессию — она станет активной.
4. Нажмите запись (кнопка или `Cmd+Shift+V`) и наговорите текст — приложение
   распознает речь, отправит в выбранную сессию и покажет ответ потоком вместе
   с действиями инструментов.

### Ручной запуск сервера

Как альтернативу можно запустить сервер вручную:

```bash
opencode serve --port 4096                       # headless-сервер
opencode attach http://127.0.0.1:4096            # (в другом окне) TUI поверх сервера
# либо сразу веб-интерфейс:
opencode web
```

Приложение находит такие серверы автоматически (по процессам `opencode` и
портам 4096/12000/3000/17000).

## Структура проекта

```
src/                    фронтенд (React + TypeScript + Vite)
  App.tsx               лаунчер (MainApp) + окно чата (ResponseView)
  ChatInput.tsx         панель ввода в чате (текст + отправка + голос)
  Markdown.tsx          рендер markdown (подсветка синтаксиса)
  sounds.ts             звуки интерфейса (Web Audio API)
  types.ts              типы
  styles.css            стили (тёмная тема)
src-tauri/              бэкенд (Rust)
  src/lib.rs            инициализация, трей, хоткеи, состояние
  src/commands.rs       Tauri-команды
  src/state.rs          AppState, ConversationStore, типы
  src/modules/audio.rs  захват звука (cpal)
  src/modules/stt.rs    распознавание речи (whisper.cpp), модели
  src/modules/opencode.rs  интеграция с OpenCode
  src/modules/automation.rs  GUI-автоматизация (заглушка)
scripts/gen_icon.py     генерация иконки
```

## Примечание про SDKROOT

`src-tauri/.cargo/config.toml` принудительно сбрасывает `SDKROOT=""` для сборки.
Это исправляет ошибку `BLAS not found` при компиляции `whisper.cpp`, если в
окружении `SDKROOT` указывает на iOS-SDK (типично для iOS/Unity-разработки).
